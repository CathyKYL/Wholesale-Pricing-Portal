## 🔧 Configuration

Edit `config.js`:

```javascript
// Toggle between demo and live data
USE_MOCK_DATA: false,  // false = live data

// Your Supabase credentials
SUPABASE_URL: 'https://your-project.supabase.co',
SUPABASE_ANON_KEY: 'your-key-here',

// Backend API
API_BASE_URL: 'http://localhost:8000',
```
